# 四位數幾A幾B遊戲｜版本三

## 一、專案介紹
本專案是使用 Google Apps Script 製作的四位數幾A幾B遊戲，透過 Google 試算表儲存玩家的遊戲紀錄，讓玩家重新開啟網頁時可以繼續之前尚未完成的遊戲。

## 二、遊戲功能
1. 玩家輸入專屬玩家代號。
2. 系統自動產生四位數答案。
3. 數字與位置都正確為 A。
4. 數字正確但位置錯誤為 B。
5. 支援多局遊戲紀錄。
6. 自動儲存每次猜測結果。
7. 重新開啟網頁可以讀取之前的遊戲資料。
8. 支援除錯模式，可以查看正確答案。

## 三、使用技術
- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets

## 四、檔案說明
- `Code.gs`：負責後端程式、玩家資料讀取與儲存。
- `Index.html`：遊戲畫面與互動功能。
